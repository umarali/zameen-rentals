# Explain the number

A measured result needs evidence that the timed work happened and produced correct outputs. Identify the limiting resource or code path, and check for errors, cache skips, untuned settings, noise and end-to-end relevance. Preserve the run count, spread and supporting artifacts with the number. A one-run exploratory measurement is a diagnostic, not proof that one implementation is faster.
