ZameenRentalBot

ZameenRentalBot is the crawler behind ZameenRentals. It reads public rental listing pages on Zameen.com to power a rental search that links each home back to its original Zameen.com listing.

What it does

It fetches public rental search pages and public listing pages, and the contact request the listing page itself offers. It does not log in, fill in forms, bypass access controls or solve challenges. It follows Zameen.com's robots.txt ↗. If robots.txt can't be fetched, it doesn't crawl.

How to recognise it

  • User-Agent: ZameenRentalBot/1.0 (+https://zameenrental.com/bot)
  • Source IP address: 165.22.91.77
  • Rate limit: at most 1 request per second. It slows down further on errors, and if robots.txt asks for a longer Crawl-delay it waits that long.
  • Signatures: requests are signed with Web Bot Auth ↗ (HTTP Message Signatures, Ed25519). The public keys are at https://zameenrental.com/.well-known/http-message-signatures-directory.

Contact and opt-out

To report a problem, ask a question, or ask us to stop crawling all or part of Zameen.com, email feedback@zameenrental.com. We'll stop promptly and reply.

ZameenRentals is independent of Zameen.com. See the privacy policy ↗ for how we handle visitors' data.
